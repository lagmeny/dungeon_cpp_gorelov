# Console Shaft — практики 1–8 (C)

Сквозной проект «Подземелье», язык C11. Используется только стандартная библиотека C.

## Сборка

```sh
cmake -S . -B build
cmake --build build
```

Или `cc -std=c++17 -Wall -Wextra -Werror -pedantic Main.cpp game.cpp map.cpp entities.cpp -o game`.

## Запуск

`./game` — карта 8×12; `./game 12 20` — карта произвольного размера (от 3 до 200);
`./game --level levels/demo.txt` — загрузка карты из файла.

Карта: `#` стена, `.` пол, `$` золото, `E` выход, `@` старт игрока в файле. Файл должен содержать прямоугольную карту, один `@`, один `E` и стены по периметру.

Команды: `north/south/east/west`, `n/s/e/w`, `go north`, `look`, `status`, `hit N`, `set/clear/toggle poisoned|blind|invisible|petrified|burning|sleeping`, `check`, `use N`, `addmonster`, `delmonster N`, `monsters`, `addresses`, `help`, `quit`.

`use N` пока демонстрирует разбор числового аргумента: инвентарь будет добавлен в следующих практиках.

## Тесты

`python3 -m unittest discover -s tests -v` — 11 интеграционных проверок с реальной компиляцией и запуском игры.

## Практики

1. Игровой цикл и команды; 2. характеристики и битовые состояния; 3. перемещение, стены, золото; 4. функции и рекурсивный поиск выхода; 5. указатели и вывод адресов; 6. собственный разбор строк; 7. динамические карта и список монстров; 8. структуры, коды ошибок, загрузка файлов, модули.

**Ограничения:** экспериментальное переполнение стека из практики 4 не воспроизводится автоматически во избежание аварийного завершения; размер карты ограничен 200×200, и фактический порог переполнения зависит от системы. Демонстрация `use` не реализует использование предметов (в этой практике требуется разбор команды). Для практики 3 фиксированный массив заменён динамическим в практике 7, как и требуется к концу практики 8.
