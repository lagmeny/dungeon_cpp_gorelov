# Подземелье — практики 11–12 (C++17)

Классы разделены по файлам: `Map`, `Creature`, `Hero`, `Monster` (и три его наследника), `Renderer`, `Game`. `main.cpp` — точка входа.

## Назначение
- `Map.hpp/.cpp`: клетки, размеры, загрузка уровня, проверка границ и инвариантов.
- `Creature.hpp/.cpp`: абстрактное существо, здоровье, координаты, чисто виртуальный `turn` и виртуальный деструктор.
- `Hero.hpp/.cpp`: герой и сбор золота.
- `Monster.hpp/.cpp`: счётчик созданных монстров и три поведения (`Chaser`, `Wanderer`, `Guard`).
- `Renderer.hpp/.cpp`: вывод карты на экран отдельно от `Map`.
- `Game.hpp/.cpp`: владение картой и существами, игровой цикл, виртуальные ходы монстров.
- `main.cpp`: запуск и создание объектов.

## Сборка в Qt Creator на Linux
Откройте `CMakeLists.txt` как проект, настройте Kit и соберите. Регистр имён `.hpp` и `.cpp` должен совпадать с `#include`.

Из терминала: `cmake -S . -B build && cmake --build build`. Запуск: `./build/dungeon_11_12` или `./build/dungeon_11_12 levels/demo.txt` (из папки проекта).

Код `Map` не печатает на экран, а `Game` владеет объектами через `std::unique_ptr`. Виртуальный деструктор `Creature` необходим для безопасного удаления наследников через указатель на базовый класс. Без виртуального деструктора такое удаление имеет неопределённое поведение.
