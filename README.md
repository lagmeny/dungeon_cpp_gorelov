# Подземелье — практики 9–10

Новый проект C++17 на основе механики практик 1–8. Старую C/C++ версию не изменяет.

## Сборка в Qt Creator
Откройте `CMakeLists.txt` как проект и запустите цель `dungeon`.

Или из терминала:

```sh
cmake -S . -B build
cmake --build build
./build/dungeon
./build/dungeon 12 20
./build/dungeon --level levels/demo.txt
./build/dungeon --demo-lifetime
ctest --test-dir build --output-on-failure
```

## Практика 9
Два класса: `Map` и `Hero`. Карта предоставляет `get`, `set`, `passable`, `draw`; герой — `move`, `takeDamage`, `status`. Команды `n/s/e/w`, `go north`, `look`, `status`, `quit`. В `Hero::move` используется явное `this`.

## Практика 10
`Map` выделяет `new[]` в конструкторе и освобождает `delete[]` в деструкторе. Копирование запрещено. У героя есть два конструктора. `--demo-lifetime` показывает порядок создания/уничтожения объектов на стеке и в куче. Для безопасного владения объектом карты в `main` используется `std::unique_ptr`. Файл полностью проверяется до создания карты; ошибки обрабатываются исключениями, память автоматически освобождается.

Внимание: по заданию №9 механики практик 2, 4–8 (монстры, битовые флаги, DFS и т. д.) **не переносятся**. Это намеренно новая, небольшая ООП-версия.
